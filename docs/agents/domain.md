# Domain Docs

This is a single-context PHP event management application with an image map, festival timetable, event details, and optional pinboard. The product is broader than a map app; use “event management” for the overall product and “map” for map-specific features.

Before exploring, read `GLOSSARY.md` if it exists and relevant decisions in `docs/adr/`. If either is absent, proceed silently; domain terms and architecture decisions can be documented there when they are resolved.

Keep terms consistent with the glossary. Surface conflicts with existing ADRs instead of silently overriding them.
